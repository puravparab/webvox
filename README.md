# Webvox

Get audio summarizes for any website, blog or paper

## Usage
1. Clone the repo with submodules:
	```
	git clone --recurse-submodules git@github.com:puravparab/webvox.git
	cd webvox
	```

2. Run notebooks:
	```
	cd notebooks
	```
 	Follow instructions in notebooks [README](./notebooks/README.md)
